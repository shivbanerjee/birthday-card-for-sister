Udita's Birthday Website
Files: index.html, style.css, script.js, assets/ (roses.jpg, pink-glow.jpg, birthday-music.mp3)
GitHub Pages: upload everything in this folder to a repo root, then Settings > Pages > Deploy from branch (main, / root).
Local: open index.html (music works best when served over http, e.g. python3 -m http.server).
